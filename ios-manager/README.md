# VK TURN Manager для iPhone

Приложение управляет серверами VK TURN Proxy по SSH. Чтобы подключаться к VPN, импортируйте выданный профиль в оригинальный VK TURN Proxy.

## Начало работы

1. Добавьте VPS с Ubuntu 24.04 или 26.04 на amd64 или arm64. Укажите IP, SSH-порт и логин. Поддерживаются вход по паролю и ключ OpenSSH Ed25519 с опциональной парольной фразой. Для администрирования нужен root либо sudo. По умолчанию для sudo используется пароль SSH. При входе по ключу можно указать пароль sudo или настроить разрешённый вход без пароля на сервере.
2. Откройте запись VPS. При первом подключении сравните показанный SSH SHA-256 fingerprint с ключом из доверенной консоли вашего провайдера. Подтвердите совпадение. Для новой установки выберите «Установить». Пакеты встроены в приложение, передаются по SFTP и проверяются перед запуском. Ubuntu должна иметь доступ к своим apt-репозиториям.
3. Разрешите входящий UDP 56004 в сетевых настройках провайдера или действующем файрволе. Создайте клиента, откройте его карточку, укажите доступный SRTP endpoint и приглашение VK Calls. Скопируйте ссылку, передайте через системное меню или отсканируйте QR-код. Ссылка и QR-код содержат приватный ключ клиента.
4. Импортируйте профиль в оригинальное приложение и подключитесь. Обновите состояние сервера в менеджере, чтобы увидеть рукопожатие и счётчики WireGuard.

В карточке VPS откройте «Диагностика SSH», чтобы скопировать последовательность событий проверки ключа, авторизации и удалённых команд. Журнал хранится в памяти приложения. Он фиксирует размеры stdout/stderr, безопасные категории ошибок и коды завершения. Сырой вывод, команды, пароли, ключи и ссылки импорта в диагностику не попадают.

Для уже управляемого сервера с рабочим конфигом, но без CLI в `/usr/local/bin` или `/usr/bin`, сначала выберите обновление встроенным пакетом. Менеджер не принимает под управление сторонние конфиги и юниты. При обрыве установки сначала обновите статус. Отключение SSH не гарантирует остановку уже запущенной системной операции. При частичной установке NAT можно включить из меню после проверки серверной конфигурации.

## Подпись и установка

Скачайте артефакт **VKServerManager-iPhone** успешного запуска **iOS Server Manager**. Он содержит неподписанный IPA, архив Xcode, SHA-256 и исходники встроенного SRTP build478. Неподписанный IPA нельзя установить на iPhone напрямую.

Для подписи собственным сертификатом создайте подписанный архив в Xcode:

1. Скачайте оба артефакта **server-manager-assets** того же запуска, сложите содержимое в `ios-manager/ServerBundle`. Создайте манифест из этого каталога командой `shasum -a 256 install.sh server-linux-* *.tar.gz > SHA256SUMS`. Для распространения добавьте лицензии и ссылку на исходники так же, как это делает workflow.
2. На Mac с Xcode 26 и XcodeGen выполните `cd ios-manager && xcodegen generate && open VKServerManager.xcodeproj`.
3. В Signing & Capabilities назначьте свою Team и уникальный Bundle Identifier. Приложению не нужны Network Extension, VPN-entitlements, App Groups или Keychain Sharing. Включите режим разработчика на iPhone, подключите его к Mac и нажмите Run. Для распространения создайте новый подписанный архив через **Product → Archive** и экспортируйте development/ad hoc IPA для зарегистрированного устройства.

Используется стандартная навигация и системные элементы SwiftUI с оформлением Liquid Glass на iOS 26 и адаптацией к системной светлой или тёмной теме. Минимальная версия системы — iOS 17.

## Проверки и лицензии

CI собирает обе архитектуры Rust-менеджера, проверяет upstream SRTP по закреплённым SHA-256 и собирает iPhone-приложение на macOS. SSH-интеграционный тест использует одноразовый Ubuntu-хост с синтетическим паролем, реальным OpenSSH и отдельным sudo. Проверяются pin, вход по паролю и ключу, SFTP, автоматическая установка, экспорт совместимого профиля, обновление, управление службами и удаление. Отдельный Rust CI проверяет Ubuntu 24.04/26.04 и совместимость исходного транспорта. Приёмка оригинального приложения на физическом iPhone описана в [документации сервера](../docs/ios-compatibility.md).

Библиотека SSH — Citadel 0.12.1 и её зависимости. Их лицензионные тексты включаются в архив. SRTP build478 — отдельный GPLv3-бинарник для серверной установки. Он распространяется вместе с текстом лицензии и соответствующим исходным архивом коммита `f954cb04ac17f49059f6fe5630a09428ff04c242`. Он не линкуется с приложением. Сохраняйте исходники и уведомления при распространении артефактов.
