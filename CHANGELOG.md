# История изменений

## v0.3.0 — серверный релиз, подготовка

### Серверный CLI

- Установка одной командой на Ubuntu 24.04 и 26.04, русскоязычное меню, QR-коды для оригинального VK TURN Proxy и переустановка SRTP с откатом и сохранением конфигурации.
- Установка WireGuard `wg-vk` и проверенного по SHA-256 сервера `srtp-build478`. Команды `install`, `status` и `uninstall` работают со своими systemd-юнитами. SRTP на UDP 56004 передаёт трафик в WireGuard на `127.0.0.1:51820`.
- `network plan/status/enable/disable` для управления IPv4 NAT и его автозапуском. Установщик использует собственную таблицу nftables и сохраняет сторонние правила.
- `client add/list/remove/export` для управления WireGuard-пирами с учётом занятых IPv4-адресов. Экспорт прямого WireGuard и ссылок импорта VK TURN производится в новые файлы с правами `0600`.
- Версионированные архивы Linux amd64 и arm64 для Ubuntu 24.04, общий манифест `SHA256SUMS` и команда `vk-turn-manager --version`.

### Подтверждённая проверка

24 ноября 2026 года владелец подтвердил развёртывание CLI на реальном VPS в `/usr/local/bin/vk-turn-manager`, выполнение `client add` и `client list`, выделение нового IPv4-адреса и создание файла импорта с правами `0600`. Ссылка успешно импортировалась в **оригинальный VK TURN Proxy** на физическом iPhone. Через туннель был доступен интернет, а WireGuard подтвердил рукопожатие и ненулевой трафик нового пира. Проверка относилась к серверному коду, использованному на VPS. [Issue #14](https://github.com/Ganzzis/vk-turn-manager-rust/issues/14)

Нативное SwiftUI-приложение из `ios/` находится за рамками серверного релиза. Проверка оригинального клиента на iPhone не подтверждает работу приложения из этого репозитория.
